# Ten and Hand & Foot local control focus

The client preserves a selected card or meld-target control across synchronous local redraw using stable card IDs or meld owner/rank, including the reachable Hand & Foot wild-edit control. Restoration requires the old control to be removed, the same account/game/room/navigation context, no modal or newer focus, and one visible enabled non-inert matching target. Existing hand-focus behavior, move payloads, rules, scoring and server state are unchanged. The unused legacy wildcard chooser is not modified.

The app-only recipe preserves 145 other modules, original MIME types, assets and settings, including the concurrent-invitation worker. Public files contain generic patches and aggregate fingerprints, not private source, family photos, credentials or a module inventory. Preview mode checks without upload; only the existing main-branch CI can deploy. Drift fails closed. Other publishers must remain paused; the final check is not an atomic global lock.

Synthetic renderer/native Chrome viewport tests do not establish physical iPhone VoiceOver focus or full-game accessibility. No real moves are made for QA.
