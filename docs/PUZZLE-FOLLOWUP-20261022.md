# Puzzle scale, perimeter spacing and manual tray drop

Forward integration on direct-Play/Home-order release d5d48bd8. This applies only the independently reviewed common-scale/ring-spacing and manual-tray-drag corrections. Five app helpers and one server geometry helper change. All other HTML and Worker bytes are compared against that live baseline, preserving direct navigation, latest Home order, TEN/artwork, accepted tray height, Preview/Play placement, gameplay engines, loader, auth and data. Configuration and the deterministic gzip build hook are unchanged.

Tray entries share one puzzle-coordinate scale. Different alpha outlines no longer magnify equal-size piece bodies differently. Natural geometry and joined-group dimensions remain meaningful; accepted tray height/zoom behavior is preserved. Tidy distributes each axis remainder across complete perimeter rings, removing the one wide seam near a bottom corner while keeping rows close, corners filled and exterior loose singles nonoverlapping. Only loose unconnected singles move. Joined/placed/held groups retain their exact state. Existing saved positions are not silently rearranged: new packing occurs when the user requests Tidy.

A deliberate tray drag keeps the grabbed offset and final chosen board drop, including the final pointer-up sample. It uses the normal drop/snap/collision protocol. A tray tap still automatically deploys inside the playable puzzle edges near the working area, without requiring a viewport slot or panning. Scroll, pinch, cancel, return-to-tray and delayed/denied network acknowledgement retain their separate behavior. Interior temporary overlap remains permitted; exterior collisions are resolved normally. No automatic solving or real family-game tests occur.

Verification covers heterogeneous body/alpha geometry, joined horizontal/vertical groups, the1014-piece aspect-ratio cases, complete ring order/protected groups, actual pointer thresholds and chosen coordinates, WebSocket/poll serialization to actual Durable Object handlers, snap/join/collision, saved progress and stale holds. Regression checks preserve direct Play and latest Home order. The package is regenerated from the exact merged HTML and checked for lossless identity; all required emitted modules and the final size are checked before publication.

Run tools/repack-puzzle-html.cjs and its --check mode after a merge. Focused tests are tests/puzzle-common-scale.cjs, tests/puzzle-ring-gap.cjs, tests/tray-manual-drag.cjs and tests/puzzle-followup-preservation.cjs. Existing protocol/Tidy/extraction/tray-render and navigation tests are also rerun. The API VM harness substitutes only the unused HTML initializer in test memory; actual compressed delivery is independently verified. All fixtures use fictional state and isolated storage, with no production moves, invitations or announcements.

Other pending header, Rummy/Bridge, board zoom/bounds and artwork work is excluded.
