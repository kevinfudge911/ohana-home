# Ohana integrated digital jukebox

This app-only release integrates the contemporary Ohana internal music display, approved collection artwork, unboxed song rows, matching searchable in-app choices, matching editor/share/Help styling, measured pagination and supported-link batch import. Exterior artwork, catalog, shared-library ACLs and audio transport remain unchanged. Worker/PuzzleRoom/storage unchanged.

Batch import supports up to100 direct supported Suno media links with editable title/artist preview, explicit Save, per-song progress, stable-request partial retries, Stop after current request, and optional playlist creation after all songs save. Audio-file hosting and automatic YouTube/Pandora playlist imports are not implemented. No new songs are added merely by publishing this UI. Normal catalog remains929.

Controlled tests pass for choices/disabled values/focus, pagination ID coverage, URL/parser bounds/duplicates, partial save/retry/request identity, audience fields and cancellation.26inline scripts parse. No actual import/save/playback test or physical device certification. Normal-site responsive browser review is pending; this release is published under the user's authorization for regular-site phone review. Do not call full visual audit or background audio resolved.
