# Current Ohana interface rules

User direction, October17,2026: commands should be free-flowing readable words and original illustrations. Use a soft individual light backing when needed for contrast. Do not restore raised blue, enamel, carved or generic rectangular button faces, or nested decorative boxes. Remove conflicting obsolete rules from their source instead of accumulating stronger overrides.

Keep native accessible command semantics, focus/selected/disabled cues and generous touch targets. Preserve actual card faces/ranks/backs, puzzle pieces/picture thumbnails, board tiles/squares, painting swatches, approved room art and family data. These are game content, not decorative command boxes.

App-created dialogs, pickers, editors and Help must match their room/activity. Jukebox screens should be an integrated contemporary Ohana digital display, preserving approved exterior art. TouchTunes Playdium is a quality/reference direction, not a copied visual identity.

Current implementation and limits are tracked in OHANA-LATEST-PRIORITIES.md and OHANA-OBSOLETE-THEME-REMOVAL.md. Historical design reports are not permission to reinstate superseded command themes.
